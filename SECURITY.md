# Security Policy

This repository is an educational demo project used for teaching secure delivery concepts. It is not intended for production deployment.

## Reporting a Vulnerability

If you believe you have found a real security issue in this repository, please report it privately through GitHub's security advisory flow:

1. Open the repository on GitHub.
2. Go to the **Security** tab.
3. Select **Report a vulnerability**.
4. Provide clear reproduction steps and the affected file or workflow.

Please do **not** open a public issue for a real vulnerability report.

## Response Expectations

Responses are best-effort. Because this is an educational project, response times are not guaranteed, but reports will be reviewed when maintainers are available.

## Scope Notes

The following intentionally vulnerable demo branches are teaching material and should not be reported as real vulnerabilities:

- `demo/01-*`
- `demo/02-*`
- `demo/03-*`
